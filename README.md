# 한 걸음 수학 · 정수와 유리수

중학교 1학년 **II. 정수와 유리수** 단원을 혼자서 한 걸음씩 익히는 웹 학습 사이트입니다.
기초학력 학생이 집과 방과후에 휴대전화로 쓰는 것을 가장 먼저 생각해서 만들었습니다.

- 로그인 없이 바로 씁니다. 기록(포인트, 진도, 복습 노트)은 각 기기의 브라우저에만 저장됩니다.
- 교과서(2022 개정 1학년) 차시와 쪽수를 맞춰 두었습니다.
- 「한 걸음 수학(입체도형)」과 같은 코드입니다. `config.js`만 다르고, 나중에 한 사이트로 합칠 수 있습니다.

## 한 차시의 흐름

**개념 → 탐구 → 단계 문제 → 연습**

1. **개념**: 접고 펼치는 카드로 핵심만 정리합니다. 파란 밑줄 낱말을 누르면 뜻이 나옵니다(양수, 음수, 원점, 절댓값 …).
2. **탐구**: 직접 누르고 움직이며 개념을 만듭니다(차시마다 활동 3개).
3. **단계 문제**: 한 문제를 작은 단계로 나누어, 한 단계를 맞혀야 다음 단계가 열립니다. 그림이 단계에 맞춰 바뀝니다.
4. **연습**: 숫자가 매번 바뀌는 문제를 반복합니다. 3번 연속 성공하면 ‘단계 없이 도전’으로 올라가고, 틀린 문제는 복습 노트(1·3·7일 뒤)로 갑니다.

## 두 가지 모델: 수직선과 칩

| | 수직선 모델 | 칩 모델 |
|---|---|---|
| 수 | 원점에서 어느 쪽으로 몇 칸 | + 칩, − 칩의 개수 |
| 덧셈 | 로봇이 첫째 수만큼, 그다음 둘째 수만큼 움직이기 | 칩을 모으고, + 칩과 − 칩 한 쌍(0 쌍)을 지우기 |
| 뺄셈 | 더하기와 반대 방향으로 움직이기 | 칩 덜어 내기, 모자라면 0 쌍 넣기 |
| 규칙 | 두 모델을 나란히 보며 ‘같은 부호면 모으기, 다른 부호면 짝지어 지우기’를 학생이 찾음 | |

뺄셈은 칩을 덜어 내다 0 쌍을 넣어 보는 경험에서 출발해, 교과서 규칙 “빼는 수의 부호를 바꾸어 더한다”로 이어집니다.

## 탐구 활동 (15개)

- **양수와 음수**: 온도계 읽기 · 반대말에 부호 붙이기 · 양수/음수/둘 다 아님 분류
- **수직선**: 점이 나타내는 수 읽기(분수 포함) · 수직선에 점 찍기 · 로봇 움직이기
- **절댓값**: 원점까지 몇 칸? · 절댓값이 같은 수 모두 찾기 · 원점에서 더 먼 수
- **덧셈**: 로봇 걷기 · 칩 짝짓기 · 두 모델 잇기 → 규칙 찾기
- **뺄셈**: 칩 덜어 내기 · 뺄셈을 덧셈으로 바꾸기 · 일교차 구하기

## 설계 원칙

- **색의 약속**: 양수는 빨강, 음수는 파랑입니다(온도계의 영상·영하와 같음). 색만으로 구별하지 않도록 언제나 +, − 기호를 함께 씁니다. 맞음/틀림은 색이 아니라 ○ · ✕로만 표시합니다.
- **예시와 비예시**: 0은 양수도 음수도 아님, 부호 없는 7은 양수, 삼각쌍뿔처럼 헷갈리는 예를 일부러 넣었습니다.
- **핵심 낱말**: “기준에서 어느 쪽?”, “방향이 부호, 칸 수가 숫자”, “0에서 몇 칸”, “모으기 / 짝지어 지우기”처럼 떠올릴 말을 정해 두었습니다.
- **입력**: 휴대전화용 키패드에 − 키와 / 키(분수)가 있습니다. −3/2와 −1.5는 둘 다 정답으로 받습니다.
- **기초 연산**: 덧셈·뺄셈, 구구단, 나눗셈, 계산 순서, 분수 기초, 어림을 함께 연습할 수 있습니다.

## 파일

- `index.html`: 사이트 전체(한 파일)
- `config.js`: 이 사이트의 설정 `{unit:'int', standalone:true}`
- `manifest.webmanifest`, `icons/`: 휴대전화 홈 화면에 추가할 때 쓰는 정보

## 나중에 합칠 때

「한 걸음 수학」 저장소의 `index.html`에 이 단원 코드가 이미 들어 있습니다(`unit:'int'`인 차시). 합칠 때는 여러 단원을 한 화면에서 고르도록 단원 선택만 넓히면 됩니다.
